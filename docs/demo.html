What this demo does and does not show

  • The scoring is real. cart.js is a direct port of cart/index.py, cart/retrieval.py and cart/phonetics.py — the same BM25 with weighted expansion postings, the same articulatory-feature edit distance, the same s = s_text + λ(1−c)·s_phonetic.
  • The collection is much smaller. This sample holds a few dozen passages against 1,896 in the experiment. IDF depends on collection size, so ranks and scores here will not match the reported tables. It is a mechanism viewer, not a reproduction.
  • Pronunciations are precomputed. Grapheme-to-phoneme conversion needs a model that cannot run in a static page, so phonemes are shipped for this sample's vocabulary. Words outside it have no pronunciation here and are reported as such.
  • Questions were chosen by a stated rule — a shared term missing from the transcript — not by whether CART happens to win. On some of them CART does not help, and you can see that.

For the measured results, with confidence intervals and significance tests, see the project page or the generated report.
